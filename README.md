# Proyek Website Portofolio Pribadi

Ini adalah proyek website portofolio pribadi *single-page* yang dibuat sebagai bagian dari Capstone Project. Website ini dirancang untuk menjadi modern, responsif, dan menampilkan informasi profesional, pengalaman kerja, keahlian, serta pencapaian.

## Deskripsi

Website ini berfungsi sebagai CV digital yang interaktif. Pengunjung dapat dengan mudah menavigasi melalui berbagai bagian untuk mengenal latar belakang profesional saya, melihat proyek yang pernah dikerjakan, dan menghubungi saya melalui formulir kontak yang terintegrasi.

## Fitur Utama ✨

* **Tema Ganda (Dark/Light):** Pengguna dapat memilih antara mode gelap atau terang yang nyaman di mata. Pilihan tema akan tersimpan di perangkat pengguna.
* **Desain Responsif:** Tampilan website dapat beradaptasi dengan baik di berbagai ukuran layar, mulai dari desktop hingga perangkat mobile.
* **Efek Mengetik (Typing Effect):** Judul pada bagian hero memiliki animasi mengetik untuk menarik perhatian.
* **Kartu Pencapaian Interaktif:** Kartu pada bagian "Achievements" memiliki efek *flip* 3D saat disentuh (hover) untuk menampilkan detail lebih lanjut.
* **Animasi Saat Scroll:** Elemen-elemen halaman akan muncul dengan animasi *fade-in* saat pengguna melakukan scroll, memberikan pengalaman yang lebih dinamis.
* **Navigasi Aktif:** Link pada navbar akan otomatis menandai bagian mana yang sedang aktif dilihat oleh pengguna.
* **Formulir Kontak Fungsional:** Menggunakan layanan Formspree untuk mengirimkan pesan dari pengunjung langsung ke email.

## Teknologi yang Digunakan 💻

* **HTML5:** Untuk struktur konten yang semantik dan aksesibel.
* **CSS3:** Untuk styling, layouting (Flexbox & Grid), variabel CSS untuk tema, dan animasi.
* **JavaScript (ES6+):** Untuk semua fungsionalitas interaktif seperti toggle tema, menu mobile, efek animasi, dan navigasi.

## Instruksi Setup

Proyek ini adalah website statis dan tidak memerlukan proses *build* yang kompleks.
1.  **Clone repository ini:**
    ```bash
    git clone https://github.com/akhmadsudaisi31-code/akhmad-sudaisi.git
    ```
2.  **Navigasi ke direktori proyek:**
    ```bash
    cd akhmad-sudaisi
    ```
3.  **Buka file `index.html`** di browser pilihan Anda. Selesai!

## Penjelasan Dukungan AI (IBM Granite) 🤖

Sesuai dengan brief proyek, model AI **IBM Granite** digunakan selama fase pengembangan untuk membantu mempercepat, meningkatkan, dan mendokumentasikan proses pembuatan kode. Berikut adalah rincian dukungannya:

1.  **Pembuatan Komentar Kode:** AI digunakan untuk menghasilkan komentar penjelasan di seluruh file `index.html`, `style.css`, dan `script.js`. Tujuannya adalah untuk membuat kode lebih mudah dibaca dan dipahami, mendokumentasikan fungsi setiap blok kode secara langsung.
2.  **Struktur dan Konten `README.md`:** AI membantu dalam menyusun kerangka dan menulis konten untuk file `README.md` ini, termasuk deskripsi, daftar fitur, dan penjelasan teknis.
3.  **Pengembangan Fitur Spesifik:** AI memberikan *snippet* kode HTML dan CSS untuk fitur **kartu flip 3D** pada bagian "Achievements". Ini termasuk debugging awal saat animasi tidak berjalan karena struktur HTML dan properti CSS yang kurang tepat.

4.  **Penjelasan Konsep Kompleks:** AI memberikan penjelasan mendalam tentang properti CSS yang krusial untuk efek 3D, seperti `perspective`, `transform-style`, dan `backface-visibility`, yang memastikan fitur tersebut berfungsi sesuai harapan.
